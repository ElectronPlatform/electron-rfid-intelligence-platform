How to request additional testing time

  1. Select Request Additional Testing Time.
  2. Your email app opens with your Installation ID and Preview status already included.
  3. Add why you would like to continue testing, review the message and send it yourself.
  4. If approved, Electron Support sends a signed Preview Extension Key. Open the section below, paste the complete key and select Apply Extension Key.

Electron prepares an email containing your Installation ID. Nothing is sent automatically.

Have you received a Preview Extension Key?

Most users do not need to do anything here. Only use this field when Electron Support has sent you a signed Preview Extension Key for this Installation ID.
